# HOUSE-PRICE-PREDICTION-USING-ML
"House price prediction using machine learning techniques with Linear Regres
Overview:

A machine learning project that predicts house prices using Linear Regression based on features like area and number of bedrooms.

🎯 Objective:

To build a simple predictive model that estimates house prices from given inputs.

🛠️ Tech Stack:
Python
Pandas
Scikit-learn
Matplotlib

⚙️ Approach:
Collected and cleaned dataset
Selected features (area, bedrooms)
Trained Linear Regression model
Evaluated model performance
Predicted prices for new inputs

📊 Result:
Model successfully predicts house prices
Example:
Input → (1200 sq ft, 3 bedrooms)
Output → ~50 Lakhs
